# L + S ❤️ – Our Little Love Story
## Run
`npm install` then `npm run dev` (open the shown URL).
## Add your files
- `public/video/video.mp4` – the ONLY file in that folder; 16:9, never cropped
- `public/music/romantic.mp3`
- `public/images/memories/1.jpg … 6.jpg` (names listed in `MemoriesGallery.jsx`; placeholders show until added)
## Deploy to Vercel
1. Push to GitHub. 2. vercel.com → Add New Project → import repo. 3. Framework: Vite, build `npm run build`, output `dist`. 4. Deploy.
No analytics, cookies, forms or external APIs. (Fonts load from Google Fonts; self-host them in `public/` for zero third-party requests.)
